# Furry 扩列墙 · 兽设名片

做一张自己的兽设扩列卡片，导出成图片直接发群里；也能把遇到的兽友收进本地扩列墙。

**纯前端，零依赖，数据全在你自己的浏览器里。**

## 在线访问

https://excuse-2580.github.io/furry-card/

## 三个功能

### 1. 我的名片

填资料，左边实时预览：

- 兽设名、兽种、头像 emoji（30 个常用款可选，也能自己输入）
- 性格标签 20 个 + 兴趣标签 18 个，支持自定义（回车添加）
- **QQ 扩列专区**：QQ 号、扩列诉求（12 个预设）、常在线时段、常驻群
- 年龄 / 身高 / 毛色 / 自我介绍（200 字）
- 8 种卡片主题色，换色整个页面配色跟着变

### QQ 扩列怎么工作

填了合法 QQ 号（5-15 位数字），名片上会出现一个**「加 QQ 好友」按钮**，对方点一下直接跳转加好友页：

```
https://wpa.qq.com/msgrd?v=3&uin=你的QQ&site=qq&menu=yes
```

用的是 QQ 公开的网页入口，手机浏览器点开就能加，对方不用装任何东西。

- QQ 号不合法（比如填了字母）就**不生成链接**，并给出提示，绝不拼出坏地址
- 勾上「分享时不显示任何联系方式」后，加好友按钮、QQ 号、导出图片里的 QQ 条**全部消失**

### 2. 扩列墙

把兽友收进来，卡片式排列，支持按名字 / 兽种 / 标签搜索，可删除、可再次分享、可复制纯文本资料。

### 3. 分享

「分享链接」把资料编码进网址 `#c=`，发给别人：

```
https://…/index.html#c=eyJuYW1lIjoi6buO5aScIiwi…
```

对方打开会**自动弹出你的名片**，确认后一键收藏到他的扩列墙。

## 关于隐私

**整个过程不经过任何服务器。** 分享链接只是把资料编码在 URL 里，没有后端、没有数据库、没有统计。

所以：

- 你的名片和扩列墙存在 `localStorage`，只在本机
- 分享链接里的内容 = 你填的内容，纯文本编码（不是加密），任何拿到链接的人都能看到
- **联系方式会写进链接**。不想公开就勾上「分享时不显示联系方式」，或者单独私发

设置页可导出 JSON 备份，也能导入恢复。

## 导出图片

用 Canvas 手绘，680×900 PNG，不依赖 html2canvas 之类的外链库。封面渐变、头像、标签胶囊、资料行、页脚都会画出来，文件名用你的兽设名。

## 技术

```
index.html   三个视图（名片 / 扩列墙 / 设置）
styles.css   Material Design 3，8 套种子色动态取色
data.js      预设标签 + 分享链接编解码 + QQ 加好友链接 + localStorage 封装
app.js       表单绑定、实时预览、Canvas 导出、导入导出
```

## 关于加好友链接

`wpa.qq.com` 是 QQ 公开的网页加好友入口，不是第三方协议，不需要授权，也没有封号风险——它就是腾讯自己的页面。这一点和 OneBot 那类第三方协议完全不同。

零依赖、零构建。双击 `index.html` 也能跑（导出图片和复制到剪贴板在非 HTTPS 下会降级，其余功能正常）。

## 已知边界

- **分享链接不是加密**，只是 base64 编码。别把不想公开的东西写进去
- 链接长度随填写内容增长，填太多可能超过某些聊天软件的消息长度限制
- 没有服务器，所以**做不了真正的多人互动**——这里是「本地收藏夹 + 名片分享」的形态
