# Furry 扩列地图

做一张自己的兽设名片，**上传头像和背景图**，在地图上标出位置，看看附近有哪些兽友。

**纯前端，零依赖，数据全在你自己的浏览器里。**

## 三个新能力

### 1. 图片上传

- **头像**：选一张手机里的照片，自动压缩成 240×240（约 3-10 KB）
- **背景**：自动压缩成 680×240（约 20-40 KB）
- 不传图就用 emoji 头像 + 渐变背景

压缩是必须的——手机原图动辄几 MB，直接存进 `localStorage`（上限约 5 MB）会瞬间撑爆。

### 2. 地图

选一个城市（**内置 347 个地级行政区**，含所有地级市、盟、自治州），或者填自定义经纬度，你的位置就会画在地图上：

- 底图是简化的中国轮廓 + 经纬网格 + **347 个城市底点**
- **你的点是红色带脉冲，兽友是主题色**
- 鼠标悬停 / 手机点击 → 显示名字和距离
- 距离用 **Haversine 公式按真实经纬度**算，不是直线像素距离
- 侧边列表**按距离排序**
- 范围筛选：全部 / 100km / 500km / 1500km
- 同城的点会自动做小圆环偏移，不会完全重叠

**选城市的三种方式**（347 个选项直接铺开在手机上没法用）：

1. **搜索框** —— 输城市名或省份，比如「枣庄」或「山东」，回车直接选中第一个结果
2. **热门城市** —— 20 个常用城市一键点选
3. **按省分组的下拉** —— 不搜索时按省级 optgroup 排列

**底图是示意轮廓，不是测绘用图**（README 和页面里都标注了）。

### 3. QQ 扩列（沿用）

填合法 QQ 号（5-15 位数字）→ 名片上出现「加 QQ 好友」按钮，用的是 `wpa.qq.com` 这个 QQ 公开网页入口。

## 隐私

**不经过任何服务器。** 没有后端、没有数据库、没有统计。

- 名片、图片、扩列墙都存在 `localStorage`
- 分享链接只是把资料编码进 URL（**不含图片**，一张图几十 KB 会让链接长到发不出去）
- 联系方式会写进链接，不想公开就勾上「分享时不显示任何联系方式」
- 设置页可导出 / 导入 JSON 备份

## 技术

```
index.html   四个视图（名片 / 扩列墙 / 地图 / 设置）
styles.css   Material Design 3，8 套种子色动态取色
data.js      347 城坐标（按省级分组）+ 中国轮廓 + 地理计算
             + 编解码 + 图片压缩 + 存储
app.js       表单绑定、实时预览、SVG 地图、Canvas 导出
```

## 城市数据

347 个地级行政区，覆盖全部地级市、地区、盟、自治州，以及港澳台。

坐标取各城市中心点，用于「看附近有谁」这个用途精度足够；**不是测绘数据**。

改动资料后会自动保存（防抖 600ms），不用手动点保存。

零依赖、零构建。双击 `index.html` 也能跑。

## 已知边界

| 边界 | 说明 |
|---|---|
| 分享链接不含图片 | 对方看到的是 emoji 头像 + 渐变背景，这是刻意设计 |
| 存储空间 | localStorage 约 5 MB。装了图的话，几十位兽友是安全的，再多可能存不下（会在保存时提示） |
| 地图底图 | 简化示意轮廓，点位按真实经纬度投影，但轮廓不用于测绘 |
| 坐标范围 | 自定义坐标限中国范围（经度 73-136，纬度 18-54），超出会提示且不上图 |
| 没有服务器 | 做不了真正的多人互动，这是「本地收藏 + 名片分享」的形态 |
